    Relatórios

    Duas visões: a saúde de cada cliente (Bloco 1) e a conferência se os alertas realmente chegaram ao destino (Bloco 2).

    Bloco 1 — Saúde da Carteira por Cliente

    Gestão de Nível de Serviço (SLA)

    O que esta seção faz: resume, para cada hospital cliente, quantos servidores PACS são monitorados, quantos incidentes (Críticos e de Atenção) foram gerados e qual percentual desses alertas teve a entrega confirmada no Slack/Jira. Serve para identificar quais clientes estão com mais problemas e quais estão com notificações falhando. O botão Exportar CSV baixa esta tabela.

    Bloco 2 — Auditoria de Divergência e Logs da Aplicação

    Gestão de Problemas

    O que esta seção faz: compara o que o sistema diz que fez (alerta marcado como enviado) com o que a API externa (Slack/Jira) confirmou. Linhas em vermelho são divergências: o MagnaSync disparou o alerta, mas ele não foi entregue (ex.: timeout ou limite de requisições). A coluna Log da Aplicação mostra o erro técnico para investigação. Use os filtros para ver só as falhas ou só as entregas.
